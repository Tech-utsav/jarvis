# JARVIS Phase 1 (PWA + secure backend)
1. Install Node 18+ (nodejs.org). 2. `cp .env.example .env`, add a free key (Groq: console.groq.com, or Google AI Studio).
3. `node server.js` then open http://localhost:3000. 4. Phone: deploy to Render (free web service, set env vars in dashboard) and open the https URL in Chrome > Add to Home screen.
No key? Offline commands (time, open apps, call, SMS draft, navigate, search) still work.
Free tiers have rate limits and may change; check the provider's pricing page.
